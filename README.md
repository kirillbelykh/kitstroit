# KitStroit

Сайт строительной компании с каталогом проектов, подробными страницами объектов, формой заявки и защищённой административной панелью. Проект объединяет публичную витрину, управление контентом и воспроизводимый Docker-деплой.

## Основные сценарии

- просмотр проектов домов и выполненных работ;
- знакомство с этапами строительства, гарантиями и командой;
- отправка заявки на консультацию;
- управление проектами, контентом, медиа и обращениями через админ-панель;
- хранение загружаемых материалов и безопасное обновление production-среды.

## Стек

| Часть | Технологии |
|---|---|
| Backend | Python 3.12, FastAPI, SQLAlchemy 2, asyncpg, Alembic, PostgreSQL |
| Frontend | React, TypeScript, Vite, Tailwind CSS, Three.js, Motion |
| Инфраструктура | Docker Compose, Caddy/Nginx, uv |
| Проверки | pytest, pytest-asyncio, TypeScript build |

## Архитектура

```text
frontend/  →  статический React-интерфейс
backend/   →  REST API, авторизация, контент и работа с PostgreSQL
infra/     →  reverse proxy и production-конфигурация
docs/      →  продуктовые, дизайнерские и эксплуатационные решения
```

Backend использует асинхронные сессии SQLAlchemy и миграции Alembic. Frontend получает публичные данные и административные операции через API. Подробности приведены в [описании архитектуры](docs/ARCHITECTURE.md).

## Быстрый запуск

Нужны Docker и Docker Compose.

```bash
cp .env.example .env
# заполните все обязательные значения в .env
docker compose up --build
```

Перед запуском задайте как минимум параметры PostgreSQL и `DATABASE_URL`, имя администратора, Argon2-хеш его пароля, случайный `JWT_SECRET`, режим окружения, каталог загрузок и разрешённые CORS-источники. Пустые строки в `.env.example` намеренны: готовые учётные данные и адреса не публикуются.

После запуска frontend и API доступны на адресах, заданных в Compose-конфигурации. Production-секреты храните только в `.env` или в хранилище секретов целевой среды.

## Разработка без Docker

Backend:

```bash
cd backend
uv sync --dev
uv run alembic upgrade head
uv run uvicorn app.main:app --reload
```

Frontend:

```bash
cd frontend
npm ci
npm run dev
```

## Проверки

```bash
make test
```

Эта команда запускает backend-тесты и production-сборку frontend. Те же проверки можно выполнить отдельно:

```bash
cd backend && uv run pytest
cd frontend && npm ci && npm run build
```

## Деплой и эксплуатация

Основные команды собраны в `Makefile`. Production-порядок, резервное копирование, откат и мониторинг описаны в [руководстве по эксплуатации](docs/OPERATIONS.md). Скрипты в `scripts/` предназначены для контролируемого merge и деплоя и требуют настройки целевой среды.

## Ограничения

Репозиторий содержит прикладной проект для конкретной компании, поэтому тексты, медиаматериалы и production-конфигурация привязаны к её процессам. Публичная копия демонстрирует архитектуру и инженерный подход, но не содержит рабочих секретов инфраструктуры.
