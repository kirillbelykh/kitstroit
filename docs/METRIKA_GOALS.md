# Цели Яндекс Метрики — счётчик 111044314

Создавать **вручную** в интерфейсе Метрики как тип **«JavaScript-событие»**.  
Автосоздание через API / tag.js **не использовать**.

Идентификаторы должны совпадать **точно** (регистр и подчёркивания):

| Идентификатор цели | Когда срабатывает |
|---|---|
| `lead_start` | Первый фокус/старт заполнения формы заявки |
| `lead_success` | Успешная отправка заявки (HTTP 201) |
| `form_error` | Ошибка отправки формы (не 201 / сеть) |
| `phone_click` | Клик по телефону |
| `telegram_click` | Клик по Telegram |
| `cta_click` | Клик по CTA (параметр `cta`) |
| `project_open` | Открытие проекта (параметр `project_index`) |
| `video_start` | Старт воспроизведения видео |
| `faq_open` | Открытие пункта FAQ (только open, не close) |

## Как создать в UI

1. Метрика → счётчик **111044314** → Цели → Добавить цель.
2. Тип: **JavaScript-событие**.
3. Условие: идентификатор цели = значение из таблицы выше (без кавычек).
4. Повторить для всех 9 целей.

Код сайта вызывает `ym(111044314, 'reachGoal', '<id>', params?)`.
